# Cognifyz Data Analysis Internship

This repository contains my successful completion of Level 1 and Level 2 tasks for the Data Analysis Internship offered by Cognifyz Technologies.

The project focuses on analyzing a restaurant dataset using Python, Pandas, Matplotlib, and Jupyter Notebook to extract meaningful business insights and perform exploratory data analysis.

---

## Project Overview

The dataset includes important restaurant-related information such as:

* Restaurant Name
* City
* Cuisines
* Price Range
* Aggregate Rating
* Online Delivery
* Table Booking
* Votes
* Latitude & Longitude
* Locality and Address

Using this dataset, I performed multiple analysis tasks to understand customer preferences, restaurant performance, and location-based insights.

---

## Tools and Technologies Used

* Python
* Pandas
* Matplotlib
* Jupyter Notebook
* CSV Dataset

---

## Level 1 Tasks

### Top Cuisines Analysis

* Identified the top 3 most common cuisines available in the dataset
* Calculated their percentage contribution

### City Analysis

* Found the city with the highest number of restaurants
* Calculated the average rating of restaurants city-wise
* Identified the city with the highest average rating

### Price Range Distribution

* Analyzed how restaurants are distributed across different price ranges
* Created a bar chart for better visualization

### Online Delivery Analysis

* Calculated the percentage of restaurants offering online delivery
* Compared average ratings of restaurants with and without online delivery

---

## Level 2 Tasks

### Restaurant Ratings Analysis

* Analyzed the distribution of aggregate ratings
* Identified the most common rating values
* Calculated the average number of votes received by restaurants

### Cuisine Combination Analysis

* Identified the most popular cuisine combinations
* Compared average ratings for different cuisine combinations

### Geographic Analysis

* Used latitude and longitude values to visualize restaurant locations
* Identified restaurant clusters across different areas

### Restaurant Chains Analysis

* Identified restaurant chains by repeated restaurant names
* Compared average ratings of restaurant chains
